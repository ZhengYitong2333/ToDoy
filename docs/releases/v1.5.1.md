# ToDoy 1.5.1

## 更新内容

- 修复本地构建、打包副本与已安装应用的系统注册冲突，避免小组件因版本不匹配停在占位画面。
- 本地更新完成后重新启动小组件扩展和桌面显示进程，解决数据已刷新、画面仍停在旧状态的问题。
- 构建号以源码版本为下限，保持主程序和小组件一致；打包退出时清理临时应用注册。
- 保留任务数据和桌面小组件布局。仅打包不会重启桌面显示进程。

## 安装与小组件恢复

退出旧版，将 DMG 中的 ToDoy 拖入 Applications 并替换，再从应用程序目录启动。不要同时运行打包目录中的副本。

上述自动清理与重启属于仓库的 `script/build_and_run.sh` 本地安装流程，直接拖拽 DMG 不会执行该脚本。如果升级后小组件仍显示占位条，可在终端执行 `killall NotificationCenter`，让 macOS 重新加载桌面小组件；布局和任务数据会保留。
