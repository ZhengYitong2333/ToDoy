# ToDoy 1.5.0

## 更新内容

- 新增「已逾期」视图和红点提醒；「我的一天」保留逾期未完成任务，「计划内」的待办排除逾期内容。
- 默认按截止时间升序排列：逾期在前，无截止时间在后；桌面小组件同步采用此顺序。
- 新增 macOS 系统提醒，支持自定义时间、清除提醒和点击通知打开任务。
- 新增每天、工作日、每周、每月、每年重复；完成后生成下一次未来任务，并保留本次完成记录。
- 参考 Microsoft To Do 简化提醒、截止日期和重复菜单；自定义时间使用月历。
- 优化侧栏悬停与按下反馈、Enter 快捷输入、抽屉外点击收起，以及任务名称和输入框字号。

## 使用说明

- 提醒、重复或日期设置修改后，点击详情侧栏底部「保存」生效。
- 首次设置提醒需允许系统通知。勿扰模式和通知设置可能影响提示；错过的提醒不补发。
- 重复任务按原始日期计算，月底和闰年自动适配。工作日仅指周一至周五。
- 重新打开历史任务不会删除或重复创建已生成的下一次任务；停止重复请修改最新的未完成任务。
