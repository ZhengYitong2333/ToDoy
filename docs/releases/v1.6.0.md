# ToDoy 1.6.0

## 更新内容

- 新增应用内更新：发现更高版本的正式 Release 后，右上角「…」显示红点。
- 在「软件更新」中直接下载更新，校验完成后安装并重新启动。
- 默认启动、回到应用（距上次尝试至少 15 分钟）和每小时检查，支持关闭自动检查与手动检查。
- 更新界面采用紧凑圆角卡片、绿色状态区和按钮，展示当前版本、上次检查时间、下载进度与版本说明。
- 网络设置折叠展示，支持为更新单独配置 HTTP / SOCKS5 代理。
- 更新保留任务和设置；安装前处理未保存的详情及快速输入，替换或启动失败时尝试恢复旧版。

## 安装

1.5.x 用户需先手动升级：退出 ToDoy，将 DMG 中的应用拖入 Applications 并替换。安装本版后，后续更高版本可通过应用内更新安装。请从可写的应用程序目录运行，不要直接在 DMG 内更新。

安装包不包含个人任务和网络配置。本次未更改任务存储格式。若需要回退，可退出应用后安装上一版，继续使用本机数据。
